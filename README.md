### Sobre o projeto

Calculadora simples feita em **Python**, desenvolvida como exercício durante meus estudos na **Alura**.

O programa recebe dois números e uma operação matemática (`+`, `-`, `*` ou `/`) e retorna o resultado.

---

### Funcionalidades

- Soma (`+`)
- Subtração (`-`)
- Multiplicação (`*`)
- Divisão (`/`)
- Validação de operação inválida
